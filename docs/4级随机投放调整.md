# 加入4级随机投放

按用户新需求，将普通投放池由1–3级扩展为1–4级。概率在 `GameConfig.ts` 集中配置：1级55%、2级30%、3级10%、4级5%。前四只仍为1、1、2、1，不会提前随机出4级。此项覆盖PRD初始三等级投放配置。

4级使用已有三花贴图和原有60单位碰撞半径。没有调整猫咪尺寸、密度、重力、合成分数或箱体尺寸；两只4级仍合成5级，基础分80。

为避免4级待投放猫顶部遮挡头部卡片，固定出生点与箱口间距由144调为120：箱口Y=230不变，出生Y从374改为350。4级身体顶部410，低于目标条底部422和下一只卡片底部424；身体底部290，仍高于箱口60单位。所有等级仍从同一个固定Y、零初速自然下落，点击只决定X。

输入区顶部根据最大投放等级自动计算为422，不再硬编码3级。下一只、等待猫、按半径限制出生X和占位判断均沿用统一等级接口。`Rules.ts` 的随机兜底等级改为配置长度，避免仍回退为3级。
