二、本轮目标

完成《猫箱挤挤》的完整灰盒玩法：

点击落猫 → 物理滚动与堆叠 → 同级合成 → 晃箱解困 → 通关或失败 → 重新开始。

手机竖屏、2D物理。用带等级数字的彩色圆球代替猫，用简单图形代替背景和纸箱。本轮优先保证规则正确、操作顺畅和物理稳定。

三、实现范围

1. 纸箱
- 左右墙与底板组成开口容器。
- 显示危险线。
- 边界与圆球尺寸统一按箱内宽度计算。
- 适配手机不同屏幕比例，按钮不能遮挡投放区域。

2. 点击投放
- 点击有效区域，在对应横坐标生成当前等级圆球。
- 根据圆球半径限制出生位置，避免穿墙。
- 显示当前等级和下一只预览。
- 投放冷却、随机概率、前四只队列按 PRD 实现。
- 按钮点击不能穿透触发投放。
- 防止多点触控、连续点击导致重复生成。
- 出生位置被占用时，不生成、不消耗当前猫，并给予提示。

3. 物理与合成
- 使用2D刚体与圆形碰撞体。
- 实现8个等级，尺寸和分数按 PRD 配置。
- 同级接触合成高一级，不同等级只碰撞。
- 三只以上同时接触时，按 PRD 稳定配对。
- 同一实体不能重复参与合成，不能重复计分。
- 合成位置靠近墙或其他猫时，做好边界与重叠处理。
- 限制异常速度，避免合成弹飞、穿墙和持续抖动。
- 视觉缩放不改变物理碰撞尺寸。

4. 晃箱
- 每局两次免费机会，显示剩余次数。
- 按 PRD 实现固定节奏的左右作用力及冷却。
- 视觉箱体轻晃，碰撞墙保持原位。
- 晃动期间禁止投放，允许碰撞与合成。
- 越线倒计时继续。
- 不可用时点击不扣次数。

5. 胜负
- 首次合成8级立即通关。
- 按 PRD 实现新投放保护、危险判定与持续越线失败。
- 不能因为猫从箱口正常下落就误判失败。
- 同一物理步内，通关优先于失败。
- 结算只触发一次。
- 提供重新开始，完整清理旧局物体、计时器、分数和状态。

6. 最小界面
- 当前分数。
- 当前猫与下一只预览。
- 晃箱按钮及剩余次数。
- 危险倒计时。
- 暂停与继续。
- 通关、失败弹窗及重新开始按钮。
- 简单操作提示。

7. 计分
- 按 PRD 实现基础分和连锁倍率。
- 普通碰撞、投放、晃箱不加分。
- 分数提交不能依赖动画完成回调。
