# 音效 V0.3 接入与验收

> 当前投放与接触4项已覆盖为[V0.4轻软pop](投放接触V0.4替换记录.md)。本文保留V0.3基底的映射与验证记录，其他音频和播放逻辑沿用。

依据 `catbox-complete-audio-v0.3/catbox-audio-full-v0.3` 的使用说明和manifest，接入18个原始WAV（17项音效与64秒BGM）。不导入MP3，不运行素材生成脚本，不逐条归一化。全部原始WAV与来源逐字节一致，48kHz、16bit、单声道。旧版6条落地变体退役，改为新版布料接触。

### 连锁升调

读取生成脚本确认基础点缀的基频为987.77Hz（B5），在本项目中离线生成+1、+3、+5、+8半音档，得到C6、D6、E6、G6。使用PCM重采样，保留幅度，不归一化，不使用引擎私有变调接口。4份衍生WAV可跨平台按普通AudioClip播放。重采样缩短点缀时长，不改变原始文件。生成参数和哈希在 `docs/audio-source/v0.3/derived-chain.json`。

## 播放与生命周期

- 音效保持3路可停止的AudioSource，主反馈优先；拥挤时低优先级点缀让位，不积压历史事件。音乐为独立循环声源，不占3路音效。
- 音效总音量0.85，音乐0.65；轻碰额外乘0.65，呼噜乘0.4。参数集中于 `AudioConfig.ts`，具体手机听感仍需配平。
- 首页首次交互后才允许BGM，不在页面加载时自动出声。正常再玩、返回首页不重启或叠加BGM。
- 暂停、切后台停止并清除短音效，暂停音乐；返回游戏或结算页须点击继续。继续时音乐从暂停位置续播，不补播历史投放、碰撞、合成或提示音。暂停界面新产生的按钮/开窗声允许播放。
- 音效与音乐独立开关，分别保存为 `catbox.muted.v1` 与 `catbox.musicMuted.v1`；最高分设置不变。旧用户首次迁移时音乐静音继承已有音效静音值，之后二者独立。
- 没有新增广告。未来广告模块可复用suspend/resume接口。

## 文件

`GameAudio.ts`：音效池、BGM、危险提示、呼噜、混音与停止逻辑。

`AudioConfig.ts`：文件时长、音量、阈值、间隔等。

`GameController.ts`：真实投放、接触分类、合成、危险和单次结算触发；音频按独立呈现时钟维护，不修改物理或计分时钟。

`GameView.ts`、`HomeView.ts`、`WinView.ts`：按钮/弹窗触发、音乐独立设置及继续播放回调。主页喇叭控制音效（含呼噜），音乐在设置中单独控制。

素材清单、原说明、原始哈希及22条运行WAV审计见 `docs/audio-source/v0.3/`。`tools/audio-check.cjs` 现指向V0.3验收套件 `audio-v03-check.cjs`。

## 验证与运行

Creator 3.8.8类型检查、9项规则检查、Web Mobile构建通过。31项新版音频检查通过，包括：22条WAV解码、真实用户手势播放、64秒循环跨越末尾、独立静音、投放/轻重落地/侧碰、静置静音、合成单次反馈、C大调档位封顶、8级仅通关音、失败仅一次、危险清除、晃箱降低5dB、呼噜让位、取消异步待播、暂停续播、不补播历史、重开不叠加BGM、两项设置存储及旧静音迁移。

38项玩法、14项失败页、13项成功页、11项生命周期回归通过。测试确认WebAudio实际播放具有非零采样的音频缓冲，没有关闭浏览器的自动播放限制。

打开 `assets/scenes/CatBox.scene` 使用浏览器预览，或 `npm run serve` 后刷新 http://localhost:8080/ 。在首页设置中分别开启音乐与音效；点击开始即可听到BGM及投放、碰撞等声音。设置截图：`audio-source/v0.3/settings.png`。

以上是文件、播放路径及规则验证，未完成手机外放、耳机、微信真机和人工听感验收。优先实测BGM循环接缝、音乐/音效相对响度、合成时点缀可辨性、呼噜音量和设备延迟。
