# 贴图接触缝隙修复

## 原因与调整

复现了 4 级三花猫落在两只 5 级猫上方的场景。碰撞圆已经接触，但手绘身体轮廓部分内缩，旋转后会出现可见细缝。

- `ArtAssets.ts`：仅对 `CatPicture` 视觉子节点增加 1.025 倍等比边缘补偿；原素材、身体圆心、刚体、碰撞半径、质量和等级配置均保持原值。待投放与预览同步使用。
- `GameView.ts`：猫咪视觉层按真实箱内左右边界和底板裁剪，上方保持开放，避免补偿边缘越出箱体。节点原点及输入坐标转换不变。
- `tools/contact-skin-check.cjs`：比较同一堆叠下的图片透明轮廓接缝，并核对刚体参数与裁剪边界。

该调整修复贴图接触处的细缝；圆形物体堆叠形成的三角形空隙仍是正常空间，不模拟软体填满空隙。

## 验证

- Cocos Creator 3.8.8 Web Mobile 构建成功；类型检查与 9 项规则检查通过。
- 38 项运行检查、76 项美术检查、11 项生命周期检查通过，覆盖投放、合成、晃箱、暂停、按钮隔离和连续重开。
- 浏览器真实 Box2D 场景中，目标接缝由约 1.3 个设计单位缩为轻微视觉重叠，物理半径及质量不变。
- 固定种子完整一局与修正前 JSON 逐项一致：124 次投放、两次晃箱、4564 分，最终失败。视觉调整未改变该局物理结果。
- 对照图：[修正前](contact-fit/before.png)、[修正后](contact-fit/after.png)、[碰撞轮廓](contact-fit/debug.png)、[手机比例](contact-fit/mobile.png)。
- 尚未在手机真机或微信小游戏环境验收。

Creator 打开项目后运行当前主场景；或 `npm run serve` 后访问 `http://localhost:8080/`，刷新已构建的 Web 试玩。
