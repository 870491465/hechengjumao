# V1.1 单猫动画验证

## 基线与范围

项目仍使用 Creator 3.8.8、Box2D 2D、原有 CatBox 场景。未找到项目或上级目录 AGENTS.md。开始时仓库没有任何提交，全部现有文件均未跟踪；将当前完整工作保存为基线提交 `3bdefcd`，标签 `v1.0-accepted-20261024`，没有撤销、覆盖已有工作。

需要独立查看旧版本时，可在项目目录执行 `git worktree add ../catbox-v10 v1.0-accepted-20261024`，从旁边目录打开旧项目，保留当前 V1.1 工作目录。

本轮只启用 1 级猫分层表现，2–8 级、箱体、UI 布局和合成动效沿用 V1.0。碰撞半径、密度、质量、重力、概率、计分、冷却和胜负逻辑不变。

## 素材映射与校准

原始目录：`E:\运营文件\猫箱挤挤\V1.1\cat-level-01-v11-validation\cat_level_01`。

运行资源只复制 `sprites/` 中的 12 张 PNG 到 `assets/resources/cat-level-01-v11/`：

| 素材 | 用法 |
| --- | --- |
| body | 身体底图，含鼻子、耳朵和腮红，不含眼嘴与四爪 |
| paw_left/right_back | 实际提供的两只后脚，叠在身体之上 |
| paw_left/right_front | 两只独立前爪，小幅探出、收拢和旋转 |
| mouth_normal | 独立嘴巴，不重复添加鼻子 |
| eye_left/right_open/half/closed | 同侧始终只显示一种，默认团身闭眼 |

顺序为身体→后脚→前爪→嘴→眼。四张姿势图、GIF 与完整角色图都是参考，未作为逐帧动画或再次叠在分层猫上。源文件、对齐、QA 与哈希记录见 `docs/art-source/level-01-v11/`。

检查了 RGBA、512×512 尺寸、透明角落和各部件 Alpha 区域；按指定层序重新拼合，与交付 assembled_round 图各通道最大差为 1/255。引擎中也检查了放大拼合效果。没有修改源 PNG。

全画布部件使用自建 SpriteFrame，不依赖自动裁切后的中心：支点节点位置为 `(pivotX-centerX, centerY-pivotY)`，图片相对支点为 `(256-pivotX, pivotY-256)`。身体实际轮廓沿用 V1.0 的拟合圆，中心约 `(255.75,263.77)`、半径约 `181.24` 个新图像素；素材的 `(256,272)` / 176 是美术近似参考，不覆盖已验收的身体校准。显示比例为真实游戏半径 / 拟合半径，继续保留 V1.0 的 1.025 倍视觉边缘补偿。

素材限制：隐藏区域为补画；前爪只适合约 ±6px、±6° 小动作。没有尾巴素材，也没有新增尾巴。边缘在手机纹理压缩后的表现仍需真机确认。

## 动作与状态

- 后续增量：用户确认增加 1 级伸懒腰。连续稳定、有支撑且没有新碰撞 10–16 秒后，播放约 1.2 秒的“轻伸身体、探爪、收回团身”；完成后重新等待随机长间隔。身体最多纵向 1.04、横向 0.975，前爪位移不超过 5 个素材像素、旋转不超过 4°，没有添加哈欠口型。等待区和首次下落不触发。
- 伸懒腰是独占姿势，先等当前眨眼结束，动作期间不叠加呼吸或果冻。有效新碰撞（含相对靠近速度达到 8px/s 的轻触）、普通有效撞击、晃箱、失去支撑或明显运动会打断并重新计时；静置接触的数值抖动不算新撞击。合成、结算、销毁仍优先。暂停和后台冻结伸展与无碰撞计时。参数位于 `LevelOneConfig.ts` 的 `stretch*`、`quietContactSpeed`、`frontStretch`、`backStretch`。
- 等待：完整拼合，前后爪向内收，半闭眼，低幅呼吸；没有上下漂移。
- 下落：约 0.08 秒从等待姿势过渡，X 0.97 / Y 1.045，前爪探出约 4/6 像素，后脚轻收。用视觉旋转补偿保持自然朝向，不修改刚体角度。
- 首次接触：仅箱底或位于下方的其他猫可触发一次；约 0.25 秒轻压、收爪、回弹至团身。擦侧墙不触发；普通接触与抖动不重复首次落地。
- 团身：视觉随物理旋转；失去支撑、滚落或晃箱时保持圆团，不重新进入首次投放姿势。后续碰撞采用克制的轻反馈，不叠加 V1.0 全幅果冻形变。
- 稳定：有支撑，线速度小于 12px/s、角速度小于 12°/s 持续 0.5 秒后进入待机；失去支撑、晃箱或超过退出阈值时离开。低幅呼吸，每只独立在 4–8 秒间隔后微睁眼约 0.28 秒：闭眼→半闭→微睁→半闭→闭眼。
- 合成锁定时停止自身状态，由原收拢快照和产物回弹接管。新模块不创建、删除或计分；即刻合成不等待落地完成。结算停止自身动画。暂停和后台冻结动画与随机倒计时。
- 不使用 Tween、schedule、setTimeout 或新增监听器；实体、预览重建与销毁显式停止和释放引用。项目没有对象池，每次新建实例恢复部件、眼睛和首次接触状态。

## 测试入口

Creator 打开 `assets/scenes/CatBox.scene`，浏览器预览。在预览地址后加参数，或用已经构建好的 Web 版本：

- 新动画单猫入口：`http://localhost:8080/?catTest=1&catAnim=1`
- V1.0 对照：`http://localhost:8080/?catTest=1&catAnim=0`
- 加 `&colliders=1` 显示物理轮廓。

单猫入口从正常等待区开始，点击箱内一次，观察等待→下落→接触→团身→待机，静置数秒看微睁眼。重复时可在开发控制台调用 `__catGame.singleCatTest()`；`__catGame.setLevelOneAnimation(false/true)` 可在保持现有物理实体和分数的情况下切换视觉。Creator GameController 组件也提供 `enableLevelOneAnimation` 开发开关。

这些入口仅在 DEBUG 环境生效，正式发布界面不增加测试按钮。正式版本启用新动画，缺少任何一张部件时整体回退 V1.0，避免显示残缺角色。

运行本地 Web：`npm run serve`，刷新以上地址。所有时间、形变幅度、爪子偏移、稳定阈值与对齐参数集中在 `assets/scripts/LevelOneConfig.ts`。

## 文件职责

- `LevelOneVisual.ts`：资源加载、分层拼合、状态、呼吸眨眼和视觉旋转过渡。
- `LevelOneConfig.ts`：单猫视觉参数与支点。
- `ArtAssets.ts`：仅 1 级优先使用新拼合，其他等级保持原实现。
- `CatEntity.ts`：从真实物理接触/速度向视觉传递状态，约束视觉边界，负责释放。
- `GameController.ts`：加载、固定步支撑检测、合成与结算打断，开发测试入口。
- `GameView.ts`：等待/下一只新拼合预览，预览计时和清理。
- `tools/level-one-animation-check.cjs`：真实引擎动画与新旧物理对照检查，`npm run test:level-one`。
