# 首页接入与验收

使用用户提供的 `catbox-home-01-art/home-assets` 下README、manifest、texts以及首页原型图复原。8张PNG原样复制到 `assets/resources/art/`，按alpha>24可见边界裁取精灵，不改动源图。透明插画与按钮均保持比例，首页猫箱是整体展示插画，不创建猫实体或碰撞体。

## 资源映射

| 资源 | 用途 |
| --- | --- |
| home-background | 首页铺满背景，等比覆盖屏幕 |
| home-logo | 顶部标题 |
| home-hero | 中部纸箱与六只猫整体插画 |
| home-score-panel | 最高分底板，叠加真实文字 |
| home-button-start | 开始游戏按钮，叠加程序文字 |
| home-button-help | 玩法说明入口 |
| home-icon-sound | 声音偏好开关，关闭时叠加斜线 |
| home-icon-settings | 设置弹窗入口 |

使用提供的texts文案，最高分首次为0，不使用原型上的1280。资源说明已指出按钮未带爪印，因此主按钮文字居中，不擅自绘制替代爪印。提供的素材为参考图重绘资源，细节与原型略有差异。

## 文件与行为

- `HomeView.ts`：首页布局、等比贴图、按压反馈、说明与设置弹窗、本机最高分和声音偏好。
- `ArtAssets.ts`：首页8张图的尺寸、可见区域与统一加载。
- `GameController.ts`：默认进入首页；首页冻结玩法；开始进入新局；暂停、结算可返回首页，清理旧局；结束、重开或返回时更新真实最高分。
- `GameView.ts`：首页与玩法视觉切换、三按钮暂停弹窗的高度适配。
- `tools/home-check.cjs`：首页真实触摸、记录读取、页面切换及连续20次进入/返回检查。

最高分、音效与音乐偏好保存于 `sys.localStorage`，分别使用 `catbox.best.v1`、`catbox.muted.v1`、`catbox.musicMuted.v1`。不保存进行中的棋盘，不增加登录或后台服务。存储不可用时退回本次运行内存状态。主页喇叭控制音效，设置页可独立控制音乐，详见《音效V0.3接入与验收》。

首页采用固定宽度适配，长屏背景等比铺满、按钮按屏高调整。开始游戏后恢复原有SHOW_ALL适配，保留已验证的物理尺寸和触摸转换。

## 运行与验收

Creator 3.8.8 打开 `assets/scenes/CatBox.scene`，选择浏览器预览，默认显示首页。Web Mobile 构建可通过 `npm run serve` 后访问 http://localhost:8080/ 。旧页面需刷新。

手机上检查：标题和猫箱不变形；开始按钮可点击且不额外投猫；玩法说明可打开/关闭；声音开关状态可切换；游戏暂停后可返回首页；返回后分数更新，重开不残留旧猫；刷新后最高分仍保留。

未进行真机、微信小游戏和低端设备内存测试；不保存未结束局。

## 本轮验证结果

- 项目类型检查、9项规则检查通过，Creator 3.8.8 Web Mobile 构建成功。
- 10项首页检查通过：初始首页冻结、真实记录、玩法说明、声音设置、开始无穿透、返回清理、跨刷新记录、20次页面往返与长屏触摸。
- 38项玩法回归、11项生命周期检查通过，包含暂停、晃箱、胜负、30次重开、首页节点销毁、5次场景重载和资源加载中断。
- 已核对720×1280首页原型构图和390×844长屏截图，8张PNG的SHA-256与源文件一致。
