# 猫箱挤挤 玩法PRD V1.0

版本：V1.0 初始玩法方案  
日期：2026年10月23日  
面向：策划、客户端开发、美术、音效、测试  
产品形态：手机竖屏休闲小游戏，首版按微信小游戏设计，建议使用 Cocos Creator 2D 实现。

本文确定首版的局内玩法、数值初值、交互反馈、局外收集及开发验收标准。所有概率、时长、尺寸和物理参数均为首轮原型测试值，不代表已经验证的留存或商业表现。名称暂定，正式上架前再确认。

## 1 产品定位与设计目标

一句话介绍：点击往纸箱里放猫，让同等级小猫碰撞合成大胖猫；空间紧张时晃一晃箱子，争取合成镇箱大橘。

核心体验是“落下去软乎乎、合起来很满足、挤成一箱很好笑”。操作以单手点击为主，猫咪被挤压时表现困倦、呆萌和放松，不表现疼痛或受伤。

目标玩家假设：喜欢猫、可爱动物、合成与碎片化解压玩法的成年休闲玩家。典型场景是通勤等候、午间休息、睡前放松。单局目标时长3—6分钟，实际时长以测试为准；玩家没有操作时不自动投猫，也没有整局倒计时。

首版需要验证三个问题：玩家能否在30秒内理解合成；晃箱能否形成可理解的策略；物理堆叠和声音能否让玩家愿意再次开始。

## 3 核心循环与单局流程

局内循环：观察当前猫与下一只猫 → 点击位置投放 → 猫咪滚动碰撞 → 同级合成 → 判断剩余空间 → 继续投放或晃箱。

完整流程：进入首页 → 开始游戏 → 首次玩家完成短引导 → 正常合成 → 合成8级猫通关，或越线持续达到阈值后失败 → 结算并更新图鉴 → 再玩一局。

通关与失败都进入结算；首版不在通关后继续原局。主动重新开始会清空本局分数与棋盘，已解锁图鉴保留。

## 4 页面及操作

### 4.1 首页

展示游戏名称、纸箱与代表性大橘、开始游戏、猫咪图鉴、最高分和设置。首页不堆叠活动入口。若存在未结束存档，主按钮显示“继续这箱”，同时提供“重新开始”。重新开始需确认一次，明确提示会结束当前局。

### 4.2 游戏页

从上到下为：分数与暂停按钮、当前目标与下一只猫预览、投放区域、纸箱主体、晃箱按钮及剩余次数。纸箱是视觉中心，广告或系统按钮不能遮挡可点击区域。

玩家可以拖动手指预览投放位置，松开后投放；直接点击则在点击位置投放。两种输入使用同一规则，默认引导只教点击。触摸开始于界面按钮、纸箱外或弹窗上时，不触发投放。

操作不依赖真实摇晃手机。游戏内“晃箱”通过按钮完成。

### 4.3 暂停与结算

暂停弹窗提供继续、重新开始、返回首页及声音设置。暂停期间冻结物理、越线计时、连锁计时和操作输入。

通关展示“镇箱大橘，接回家啦”；失败展示“这箱猫，含橘量超标了”。两者均展示本局分数、最大猫、最高连锁、首次解锁内容和棋盘合影；按钮为“再装一箱”“返回首页”，分享入口在平台支持时显示。最高分只在超过旧记录时更新。

## 5 猫咪等级与尺寸

猫咪等级通过轮廓、花色、表情和名字共同区分，不能仅依赖颜色。所有等级碰撞体均为圆形，耳朵、尾巴、肉垫不参与碰撞。

以纸箱内宽 W 为尺寸基准。下表半径不含耳尾，最终贴图需保证圆形主体与碰撞体一致，避免“看起来碰到了却不合成”。

| 等级 | 名称 | 形象方向 | 半径/W | 该等级合成产物分数 |
| --- | --- | --- | --- | --- |
| 1 | 奶团猫 | 奶白、小圆团、蜷缩 | 0.040 | 不直接计分 |
| 2 | 糯米猫 | 浅灰白、露一只肉垫 | 0.055 | 10 |
| 3 | 面包猫 | 浅棕、趴卧、圆润面包形 | 0.075 | 20 |
| 4 | 围兜猫 | 奶白配深色围兜、抱肚 | 0.100 | 40 |
| 5 | 橘团猫 | 橘白、脸颊变宽 | 0.135 | 80 |
| 6 | 肚兜猫 | 橘色、肚皮明显、半仰躺 | 0.180 | 160 |
| 7 | 猫老板 | 深橘、眯眼、大圆肚 | 0.240 | 320 |
| 8 | 镇箱大橘 | 金橘、放松摊睡、标志性肉垫 | 0.310 | 640 |

同级两只合成下一级：1+1→2，依次到7+7→8。不同等级不能合成。8级生成后直接触发通关，不存在8+8。产物半径小于原两猫的面积等效半径，合成会适度释放空间；尺寸表是玩法参数，不能在换皮时随意调整。

## 6 投放与随机规则

### 6.1 可投放状态

仅在正常游玩且投放冷却结束时接受一次投放。投放后进入短暂冷却，初值0.6秒；不要求整箱猫完全静止后才允许下一次投放。多点触控只处理第一个有效触点，冷却期间额外点击直接忽略。

下一只预览固定展示一只。投放时使用当前猫，随后把预览猫变为当前猫，再抽取新的预览猫。打开暂停、警告、切后台均不能重抽。

### 6.2 出生位置

投放猫圆心 X 夹在箱内左边界+r+安全间距与右边界-r-安全间距之间。初值安全间距0.01W。

纸箱为左右墙与底板组成的开口容器。出生圆心位于箱口上方0.08W处；新生猫下落至与箱内其他猫或底板首次接触后，才成为越线判定对象。若该位置与已有猫重叠，则本次不生成、不消耗当前猫，提示“这里有点挤，换个位置试试”。

### 6.3 出猫概率

| 掉落等级 | 概率 |
| --- | --- |
| 1级 | 60% |
| 2级 | 30% |
| 3级 | 10% |
| 4—8级 | 0% |

每个正式新局的前四只固定为1、1、2、1级，第五只开始按上述概率独立抽取。首版不根据输赢、分数或付费情况改变概率。保存随机状态或完整预生成队列，确保恢复游戏不会改变后续出猫。

## 7 碰撞与合成规则

### 7.1 合成事务

两只未锁定、未删除、同等级猫的实体碰撞体接触时即可合成，不要求停稳。一次合成事务需要完成以下操作：锁定并移除两只源猫；计算产物位置；创建高一级猫；计分；记录图鉴；播放反馈。

合成产物中心优先取两只源猫中心的中点，再夹回纸箱合法范围。若与第三只猫重叠，采用有限次数位置修正：优先向上寻找最近无穿透位置，单次总位移不超过产物半径；仍无法消除重叠时允许物理解算处理，但须限制分离速度，不能产生爆炸式弹飞。

合成视觉动画约0.22秒。逻辑结果以事务提交为准，动画不得再次触发计分。产物经过0.10秒保护后可继续参与合成，保护只屏蔽合成，仍参与正常碰撞。

### 7.2 多猫同时接触

同一物理步内先收集候选，再按“中心距离由近到远、距离相同按实体生成ID”排序，依次配对。每只猫一物理步最多参与一次合成。三只同级猫同时接触，只能消耗其中两只，第三只保留。重新检查实体存活与锁定状态，避免重复计分或生成重复产物。

### 7.3 软乎乎的表现

美术节点与物理节点分离。落地时贴图沿受力方向轻压再回弹，碰撞体不跟随缩放；挤压面部、眨眼、耳朵抖动均为表现。静置时猫咪进入轻微呼吸动画，不持续给刚体施力。

合成可以给邻近猫一个小幅、有限的分离冲量，按距离衰减并限制最大速度。该冲量只增加滚动机会，不保证连续合成；若造成随机弹飞，原型阶段应先关闭。

## 8 晃箱机制

每局两次免费使用机会，次数不跨局累积。按钮展示“晃一晃 2”，用完后展示“本局已用完”。基础版不额外售卖次数。

| 参数 | 初值 |
| --- | --- |
| 单次动作时长 | 0.8秒 |
| 按钮冷却 | 动作结束后3秒 |
| 视觉左右位移 | 最大0.015W |
| 使用次数 | 每局2次 |
| 操作条件 | 正常游玩或越线警告，非投放冷却、非合成事务提交、非晃动中 |

视觉上箱子整体左右轻晃；碰撞墙保持原位，使用固定的左右交替加速度曲线作用于猫咪，避免移动墙体把猫推出箱外。刚体速度变化须有上限；相同棋盘和输入应产生近似结果。

动作开始后扣除一次，播放猫咪一起睁眼、肉垫滑动等反馈。期间禁止投放，允许物理碰撞、合成、连锁计分。越线计时照常进行，晃箱不能暂停失败倒计时。

按钮可用条件不满足时不扣次数。动画或应用切后台不能重复发放或重复扣次。若晃动中触发通关或失败，立即终止晃动，进入结算流程。

## 9 胜负与越线判定

### 9.1 通关

本局生成第一只8级镇箱大橘即通关，立即停止新投放和越线累计，提交本次合成分数与图鉴。播放约1.5秒的庆祝效果，再进入结算。同一物理步同时满足通关与失败时，先处理有效合成与通关，通关优先。

### 9.2 危险线与失败

以箱内底部为 Y=0、箱口为 Y=H，箱内高度初值 H=1.35W，危险线为0.93H。已参与箱内碰撞的猫，若圆心Y+半径高于危险线，且已过投放保护期，视为危险猫。

每只新投放猫从生成开始有1.2秒越线保护，用于正常下落；合成产物继承两只源猫中较早的保护结束时间，不重新获得完整保护，防止合成不断刷新免死时间。

任一危险猫存在时启动全局连续越线计时；持续3秒判负。期间危险猫身份变化但仍有其他危险猫时，计时不重置；当所有猫都回到线下连续0.2秒，计时清零。进入越线警告时红线显现、轻微呼吸闪烁，显示剩余时间，允许玩家继续投放或使用可用的晃箱。

不因瞬间弹起直接失败。判负后冻结棋盘，先展示失败状态；商业化开关关闭时直接结算，开启时进入可关闭的复活弹窗。

### 9.3 可选激励复活

每局最多一次。广告不可用、取消或失败均不发奖；完整观看成功后按奖励事务处理：移除全部1级和2级猫，若移除数量少于3只，则从剩余猫中按等级从低到高、同级按位置从高到低补足到3只；棋盘不足3只时移除所有现存猫。仅在失败后使用，不会移除已产生通关结果的8级猫。

移除不计合成分数、不增加连锁、不解锁图鉴。清零危险计时并给予3秒越线保护，给予0.8秒自动下落整理时间，再恢复输入；保护期结束后按普通越线规则重新判定。保留原分数、队列和剩余晃箱次数，不保证一定挽救本局。

免费重新开始始终可用。广告奖励按唯一事务ID落盘，重复回调不能重复清猫；切后台恢复后继续同一奖励事务，不重播已完成奖励。

## 10 分数与连锁

单纯投放、碰撞和晃箱不加分，只有成功合成加分。基础分见猫咪等级表，按产物等级计算。

首个合成开启一组连锁；后续合成若距离上一次成功合成不超过1秒，则连锁数加1，超过1秒开启新组。接受一次新投放或一次新晃箱时，先结束旧组，因此连锁主要记录单次操作引发的连续结果。

| 当前连锁序号 | 分数倍率 | 文案 |
| --- | --- | --- |
| 第1次 | 1.0 | 不展示连锁文案 |
| 第2次 | 1.2 | 连成一团 |
| 第3次 | 1.4 | 越挤越圆 |
| 第4次 | 1.6 | 一箱都醒了 |
| 第5次及以上 | 1.8 | 大橘为重 |

单次得分=基础分×倍率，四舍五入为整数。同一物理步的多个合成按第7节的配对提交顺序累计。无跨局倍率或付费分数加成。本局最高连锁记录单组最大合成次数。

## 11 新手引导

首次玩家进入专用引导局：底部预放一只1级猫，当前猫为1级，手指提示“点这里，放下小猫”；玩家完成第一次合成后提示“同样的猫，碰在一起会变大”。

随后用预置小堆叠展示被隔开的同级猫，提示点击晃箱并完成一次合成。引导阶段暂停失败判断，不弹广告，约20—30秒完成；退出后可重新进入或跳过。

引导局不计最高分、不解锁图鉴。完成或跳过后开启全新正式局，空箱开始，按正式前四只队列发猫，并给满两次晃箱。引导完成状态永久保存，设置内可重看。

## 12 图鉴与长期动力

图鉴展示8个等级，未解锁猫显示清晰剪影、等级与名称；通过正式局合成首次获得该等级后解锁。1级在首次正式投放后解锁，2级及以上必须实际合成获得，随机投出2级或3级不直接解锁。

每条图鉴包含名称、完整形象、一句性格文案及首次解锁日期。例如镇箱大橘：“工作可以等等，这个箱子我先躺。”首次解锁仅以局内轻提示展示，不中断操作，结算时汇总。

后续房间玩法让解锁猫出现在窗台或地毯上；首版只完成图鉴，不提前引入摆件经济系统。

## 13 美术与音效需求

整体采用暖色、清楚、轻松的2D卡通表现。牛皮纸箱、奶油色室内光和橘猫形成视觉主调；猫咪轮廓干净，适合小屏幕识别。避开大量粒子、强闪光和失败时的压迫感。

| 资源 | 首版数量与要求 |
| --- | --- |
| 猫咪主体 | 8级，各一套可独立缩放的主体贴图，背景透明 |
| 角色表现 | 每级至少待机、落地压扁、合成回弹、挤压表情，可复用骨骼或程序动画 |
| 图鉴 | 8张剪影，优先由原角色资产生成 |
| 环境 | 1张室内背景，箱前板、后板与碰撞区域分离 |
| 特效 | 合成轻泡、连锁数字、解锁提示、通关效果 |
| 界面 | 暂停、声音、晃箱、预览、结算及通用弹窗 |
| 声音 | 轻落地、重落地、普通合成、大猫合成、晃箱、危险提示、通关、失败、按钮 |

落地声以纸箱轻响、软垫拍击为主；合成声采用短促“噗叽”配温润尾音。单个合成音初值150—350毫秒。连续合成最多同时播放3个主要反馈音，低优先级落地声限频，避免叠加噪声。呼噜声仅作为低音量环境层，背景音乐与音效独立开关，默认不持续喵叫。

## 14 技术边界与存档

### 14.1 物理实现

建议使用2D刚体和圆形碰撞体，固定物理步长1/60秒，重力初值为-1.8W/秒²，恢复系数0.10、摩擦系数0.35、线性阻尼0.4、角阻尼0.8；具体字段由引擎适配，保证上述单位语义后再调参。质量按圆面积成比例设置，统一材质密度，避免小猫轻易撞飞大猫。

物理速度上限初值1.5W/秒，晃箱净速度增量上限0.25W/秒。物理休眠用于稳定静置猫，晃动时主动唤醒。若堆叠抖动，先检查碰撞体、出生重叠和求解精度，再调整参数。

合并期间需统一处理实体删除与生成。猫的唯一ID、等级、位置和逻辑锁状态由玩法层管理，动画回调不能决定唯一的奖励提交。

### 14.2 状态管理

主状态为首页、引导、游玩、暂停、复活弹窗、通关结算和失败结算。游玩内部单独维护投放冷却、晃箱、合成保护和危险计时，避免把所有组合状态写成相互覆盖的主状态。

结算提交具备幂等性：同一局只写一次结果，重复按钮点击或重复回调不产生多份奖励、成绩或新局。

### 14.3 存档与恢复

保存局ID、规则版本、棋盘实体及速度、当前猫、预览猫、随机状态、分数、连锁记录、已用晃箱次数、复活使用状态、危险计时和保护剩余时间。长期数据包括最高分、已解锁图鉴、首次解锁日期、引导状态和设置。

在投放、合成事务、晃箱扣次及广告奖励完成后的安全节点保存；切后台先完成当前可提交事务并保存，再冻结游戏。返回前台展示“点击继续”，继续后恢复物理与计时，不累计后台时间，也不重置危险计时。

重建棋盘时暂停物理与合成检测，实体全部恢复后再开始；保存的局内保护时间按剩余游戏时间恢复。存档损坏或规则版本不兼容时保留长期数据，提示本局无法恢复并提供新局，不静默覆盖成绩。

### 14.4 性能验收目标

在项目选定的中低端基准机上，以60只猫的堆叠场景连续运行5分钟，目标平均帧率不低于30fps，无穿墙、实体持续增加或明显内存持续增长。上线前需把具体机型写入验收记录；这里是验收目标，尚非实测结果。

## 15 数据记录与调优

| 事件 | 关键字段 | 观察用途 |
| --- | --- | --- |
| game_start | 局ID、规则版本、是否首次、是否恢复 | 统计正式开局 |
| tutorial_step | 步骤、完成状态、游戏时长 | 判断理解卡点 |
| cat_drop | 局ID、等级、次数、当前猫数量 | 判断操作与空间压力 |
| cat_merge | 源等级、产物等级、连锁数、得分 | 判断合成节奏 |
| shake_used | 剩余次数、使用前危险状态 | 判断使用时机 |
| shake_result | 触发后2秒内合成次数 | 衡量晃箱效果，排除后续新投放窗口 |
| danger_enter / danger_exit | 剩余空间、猫数量、最大等级 | 判断失败是否突兀 |
| game_end | 通关或失败、有效时长、投放数、分数、最大猫、晃箱次数 | 分析难度分布 |
| revive_result | 广告结果、是否完成奖励 | 判断复活流程 |
| replay_click | 前一局结果、局ID | 观察再玩意愿 |

主动退出作为独立退出事件记录，不伪装成失败；有效时长排除暂停与后台时间。game_end每局只报一次，仅在最终通关或放弃复活后失败时提交。进入复活弹窗先记录危险失败触发事件，避免复活局被重复计算。

首轮建议邀请10—20名目标玩家观察试玩。检查能否无口头解释完成首次合成、是否主动使用晃箱、是否理解失败原因，并记录单局时长分布、最大等级分布和再开局比例。小样本用于发现问题，不据此宣称已验证留存或收益。

若普遍卡在低等级，优先调出猫概率、尺寸与箱体空间；若操作无策略，检查预览是否清楚、晃箱是否可预期；若太吵或太乱，先降低碰撞回弹与音效密度。一次只调整一组关键变量，保留规则版本用于比较。

## 16 玩法验收清单

| 场景 | 预期结果 |
| --- | --- |
| 两只同级猫接触 | 恰好消耗两只并生成高一级一只，计分一次 |
| 不同等级接触 | 发生碰撞，不合成 |
| 三只同级猫同帧接触 | 只合成一对，剩余一只不被误删 |
| 产物紧邻同级猫 | 保护结束后可以继续合成，无重复产物 |
| 连点与多点触控 | 冷却内不额外生成猫，不跳过队列 |
| 点击左右边缘 | 猫圆心按半径夹回合法区域 |
| 出生位置被占用 | 不生成、不扣当前猫，提示换位置 |
| 正常从箱口落下 | 保护期内不误判失败 |
| 猫短暂弹到线上 | 未持续达到阈值时不结束 |
| 危险猫发生替换 | 箱内一直存在危险猫时，计时不重置 |
| 晃箱时越线 | 倒计时继续，不获得额外免死 |
| 晃箱不可用时点击 | 不扣次数，不产生物理施力 |
| 合成8级同时满足越线 | 通关优先，结算只出现一次 |
| 连锁间隔与新投放 | 按1秒窗口及新操作重置规则计分 |
| 暂停或切后台 | 物理、倒计时、冷却均冻结，恢复不重抽猫 |
| 广告取消或加载失败 | 无奖励；玩家可免费结算或重新开始 |
| 广告成功重复回调 | 仅清猫一次，仅消耗一次复活 |
| 引导结束 | 新开正式局，分数归零、晃箱为2次 |
| 图鉴首次解锁 | 仅记录一次，随机掉落不越过解锁规则 |
| 重新打开游戏 | 可恢复原棋盘、分数、队列和已用次数 |
| 长时间堆叠 | 无持续抖动、明显穿墙或不可控弹飞 |

## 17 开发顺序与交付标准

| 阶段 | 工作内容 | 完成标准 |
| --- | --- | --- |
| A 灰盒原型 | 圆形代替猫、纸箱、投放、8级合成、危险线 | 能从开局玩到通关或失败，逻辑验收通过 |
| B 特色玩法 | 晃箱、预览、连锁、参数配置 | 晃箱次数与失败规则一致，连锁可复现验证 |
| C 治愈反馈 | 猫咪贴图、回弹、表情、声音 | 猫等级清楚，反馈舒服，物理表现不受视觉缩放干扰 |
| D 完整闭环 | 首页、引导、图鉴、结算、暂停、存档 | 不依赖调试按钮完成完整体验 |
| E 试玩调优 | 埋点、目标设备性能、难度调整 | 完成试玩记录，解决误判、卡死和操作歧义 |
| F 可选商业接入 | 激励复活及平台分享 | 广告失败可退出，奖励幂等，核心循环无需广告也能完成 |

最小可玩原型优先交付A和B。美术投入前先验证：落猫位置影响结果，碰撞合成准确，晃箱确实能改变局面，失败原因玩家能理解。验证通过后再完成8级正式猫咪资产。

## 18 后续版本方向

V1.1可增加两到三个纯视觉箱子主题与更丰富的猫咪表情，不改变碰撞尺寸。V1.2增加猫咪小屋，让图鉴中的猫出现在固定场景，摆件通过明确成就解锁。后续再考虑特殊箱形、每日种子挑战和无尽模式，每种模式分别配置胜负与计分规则。

产品卖点保持集中：一箱会打呼噜的猫，越合越胖；空间不够，晃一晃，再挤出一只大橘。
