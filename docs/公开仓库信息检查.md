# 公开仓库信息检查

检查日期：2026-10-25。

## 范围与方法

检查了远程 `main`、V1.0 标签所能到达的全部 4 条提交及当前工作区。历史中共 320 个文件版本，其中 209 个可解码文本版本。使用本地规则扫描常见令牌格式、私钥头、密码/密钥赋值、带凭据 URL、微信 AppID、邮箱及本机绝对路径，并人工查看代码的网络调用、平台配置和可疑结果。

另外检查了当前仓库图片的可读元数据、WAV 附加信息块，并抽查玩法 GIF 的 5 帧。没有使用第三方凭据验证服务，没有把文件上传到其他扫描服务。此检查不等同于全量专业安全审计，也不能保证识别所有自定义凭据或图片里的文字。

## 已清理

- 将文档中的本机绝对目录改成素材包名或仓库相对路径。
- 将历史验收文档中的实际局域网 IP 改为通用说明。
- 追加 `.env`、私钥、签名材料、平台私有配置及日志等忽略规则。忽略规则不能移除已进入 Git 历史的文件。
- 本次清理提交使用 GitHub noreply 邮箱，不在新提交中继续写入原作者邮箱。未改动开发者全局 Git 身份配置。

## 仍保留在历史中的信息

三条既有提交的作者和提交者字段含作者原邮箱。旧文档版本中的本机目录和局域网 IP 也仍可通过历史查看。它们不是账号密钥，但属于可以减少的个人/环境信息。

普通删除或新提交无法擦除上述历史内容。当前没有重写或强制推送公开历史，也没有删除 V1.0 回退标签；若决定彻底移除，需要同时处理主分支、标签和历史提交作者信息，再协调已有克隆。已经下载的副本不会随历史重写自动消失。

GitHub 提交邮箱隐私还需在账号设置中启用，并将本地提交邮箱设为账号页面给出的 noreply 地址。不能用清空 README 邮箱代替这一步。
