# 投放与接触音 V0.4

按用户提供的 `v1.0/catbox-touch-v04/说明.txt`，使用48kHz、单声道、16bit WAV原文件，替换以下4项。素材属于程序合成的卡通轻软pop，并非实录。MP3不导入，原文件不归一化、不改写。

| 文件 | 触发 | 时长 |
| --- | --- | --- |
| cat_release.wav | 投放成功 | 85毫秒 |
| land_soft.wav | 1–3级有效落地/上下接触 | 145毫秒 |
| land_heavy.wav | 4–8级有效落地/上下接触 | 190毫秒 |
| cat_bump.wav | 有效侧向碰撞 | 85毫秒 |

文件存放在 `assets/resources/audio/`，保留原资源UUID，`AudioConfig.ts`同步更新投放及重落地时长。触发、接触节流、同次合成不叠加接触声、3路音效限制、音量系数及开关保持原有设置。其余18个运行音频文件与替换前哈希一致，包括合成声、BGM、胜负、界面、危险、呼噜及连锁点缀。

原说明及4个源文件哈希见 `audio-source/touch-v0.4/`。本轮类型检查、9项规则检查及Creator 3.8.8 Web Mobile构建通过；32项音频检查通过，并新增校验：浏览器实际加载的4条音频原生文件SHA-256与项目中的新WAV完全一致，排除旧缓存或仅改文件名的情况。真实投放、轻重落地和侧碰播放路径均已验证。

运行：Creator打开 `assets/scenes/CatBox.scene` 使用浏览器预览，或刷新 http://localhost:8080/ 。确认首页设置的音效开关已开启。手机外放、耳机和微信真机实际听感仍待确认。
