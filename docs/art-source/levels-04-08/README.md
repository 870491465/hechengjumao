## 游戏接入
PNG为原图，WebP为质量90压缩版本，两套内容相同，任选一种使用。默认优先PNG；使用WebP前确认目标引擎与平台支持带透明通道的WebP。

每张图有透明留白，不能直接把整张画布宽度作为猫咪碰撞直径。manifest.json记录图片尺寸和alpha阈值24下的可见包围框（XYXY，右下不包含），供布局对齐参考。耳朵属于视觉装饰，可见包围框不等于圆形碰撞体。

建议物理节点使用CircleCollider2D，精灵作为独立子节点；按圆形身体中心校准贴图偏移，再按已有各等级碰撞半径设置显示大小，确保落地和贴墙时身体不明显穿插。中心锚点可先设为(0.5,0.5)，仍需在游戏里显示碰撞圆进行最终对齐。

本包没有擅自调整既有物理参数，也尚未接入Cocos做碰撞、旋转和合成验证。五张预览画布占比接近，实际游戏中的体型递增由等级配置控制，不是靠原文件像素尺寸控制。

同等级使用同一张固定花色贴图；4→5→6→7→8逐级合成，首次产生8级触发成功结算，不再生成9级。
