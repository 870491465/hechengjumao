# 猫箱挤挤 · 成功结算页资源

共8张资源。背景直接复用用户提供的游戏页原图，其余透明素材按结算效果图分别重绘，细节可能略有变化。

- game-background：游戏页原始背景，未经重绘。
- win-title：合成成功标题，含星星装饰。
- win-hero：橘猫和纸箱整体透明插画，供结算展示。
- win-celebration：独立光芒和彩纸，置于主插画后方。
- win-score-panel：空白双列得分底板。
- win-record-badge：含“新纪录”文字的徽章。
- win-button-replay：无字橙色主按钮，复用首页底图。
- win-button-home：无字浅色次按钮，复用首页底图。

## 接入
层级从后向前：原背景→庆祝装饰→主插画→标题、得分和按钮→程序文字。
所有贴图保持比例；透明留白包含在原尺寸中，需按可见轮廓对齐。参照结算效果图摆放，根据手机安全区调整。
副标题、分数、按钮文字由程序绘制，文案见texts.json；得分从本局数据读取，最高分从存档读取。只有刷新最高分时才显示新纪录徽章。
主按钮按下效果可用0.96缩放实现。猫咪与纸箱目前为整体素材，不可分别做动作，也不作为游戏内碰撞贴图。

PNG为生成原图；WebP为质量88压缩版本，保留透明通道。两种格式任选一套，避免重复加载。manifest.json记录尺寸。

生成方式：imagegen内置工具，参考最终成功结算页，分别制作透明标题、橘猫纸箱、得分底板、新纪录徽章和庆祝层；背景与按钮使用现有资源。
