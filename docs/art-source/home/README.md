# 猫箱挤挤首页素材 V1

按首页参考图分别重绘生成，细节与原图可能略有差异。PNG 原尺寸交付，文件名全部为英文。

## 资源
- home-background：竖屏场景背景，不含标题、猫箱和按钮。
- home-hero：纸箱与六只猫的整体透明主插画，适合首页展示，不是游戏内单只猫或碰撞素材。
- home-logo：透明标题。
- home-button-start：无字主按钮。
- home-score-panel：无字分数底板。
- home-button-help：无字说明按钮。
- home-icon-sound：声音入口。
- home-icon-settings：设置入口。

## 接入
背景铺满竖屏；其他资源等比缩放并使用中心锚点。透明资源自带留白，布局时按可见轮廓对齐。标题位于顶部约 16%，主插画位于中部约 48%，分数底板约 71%，开始按钮约 80%，说明按钮约 93%。根据屏幕比例和安全区调整，不要把图片拉伸变形。

按钮文字和分数请使用程序文字叠加，配置见 texts.json，实际最高分从存档读取。主按钮当前未内置爪印，文字可居中显示。仅提供默认按钮状态，按下可由程序缩放到 0.96 并略降亮度。

manifest.json 记录原尺寸及透明通道。两个压缩包解压到同一目录即可合并。

生成方式：imagegen 内置工具，以原首页图为风格与构图参考，分别生成背景、透明主插画、标题、无字按钮和图标。
