# 猫箱挤挤 · 第一批分层素材 V1

按确认的暖奶油色、牛皮纸与柔和手绘猫咪风格制作。素材由 imagegen 逐张生成。所有 PNG 原始文件均保留；文字不烘焙进背景或按钮。

## Cocos 接入

图层顺序：背景 → 箱后板 → 程序危险线 → 猫咪 → 箱前沿 → 按钮底图 → 文字。可将侧板保留在后板层；侧板透视不能作为碰撞边界。

猫咪采用中心锚点，物理节点与美术子节点分开。每级固定一套花色和姿势。manifest 的 sourceRect 是有效绘制区域，用于排除透明留白与极低透明度边缘噪点；原始画布尺寸不能直接当成猫咪直径。美术有效区域缩放为直径 2r，主体与碰撞圆的近似差异可在验证页检查，耳部微小偏差仅为装饰，不加耳朵碰撞体。

1—3级半径依次为箱内宽 W 的0.040、0.055、0.075；W=320时为12.8、17.6、24。箱内高=1.35W；危险线在自底向上0.93H，普通状态淡显。边界以直线的左右内墙与底板为准。源图内边界归一化坐标见 manifest，仅用于美术对齐；实际引擎尺寸以场景中的W、H为准。

当前独立验证页使用固定1/60秒步长的简化圆形解算器，含重力、碰撞、摩擦和旋转，并非 Cocos 原型；其手感不能替代引擎实机验证。1级猫尺寸较小，应优先在实际手机检查识别度与贴图锯齿。静态素材本批完成，呼吸、落地压扁与表情动画尚未制作。

## 建议实机验收

依次检查单猫落底、贴墙滚落、大小猫相互支撑、连续投放、28只混合堆叠、晃箱后稳定。确认碰撞圆与美术轮廓接近、无明显悬空/穿墙。再关闭碰撞圆检查小屏识别度。最终需在原Cocos工程和目标手机完成同样验证。
