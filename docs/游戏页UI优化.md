# 游戏页 UI 优化

本次按用户提供的第二张原型图调整头部、底部，保留 Cocos Creator 3.8.8、现有场景、投放坐标、箱体尺寸和全部物理规则。

- 头部：移除通栏底板；描边标题与爪印、独立分数卡、目标条、下一只卡片、圆形暂停按钮。
- 当前猫：以箱口上方真实尺寸的待投放猫作为当前预览，增加渐隐落点虚线，不创建额外刚体。
- 底部：移除通栏底板；放大既有橙色按钮，增加纸箱图标、独立次数角标与冷却状态；底部使用“挤一挤，大橘有望”。投放受阻时仍显示实际提示。
- 动态内容：分数、最高连锁、下一只、剩余次数和冷却全部读取真实局内状态。

## 与原型图的素材差异

标题现已替换为用户补充的透明 PNG：`assets/resources/art/game_logo.png`，原图 2172×724。运行时裁取有效标题区域（保留边缘余量），等比显示，移除原文字标题及旁边的重复爪印。原文件不修改，缩小时启用支持设备上的 mipmap。为标题留出高度，分数卡略微压缩，投放区不变。

仍缺少独立暂停图标、纸箱按钮图标和8级猫，图标使用 Cocos Graphics 绘制。目标用数字 8 标记，不用低级猫冒充。原型图的历史最高分位置显示现有的“最高连锁”，本次不新增存档或伪造最高分。

## 修改与运行

主要代码：`assets/scripts/GameView.ts`。`tools/art-check.cjs` 增加卡片、真实数值、次数角标、暂停位置检查；`tools/runtime-check.cjs` 更新暂停按钮实际触点。

Creator 打开 `assets/scenes/CatBox.scene`，使用浏览器预览。已更新 Web Mobile 构建，运行 `npm run serve` 后访问 http://localhost:8080/ 。旧预览页面需要刷新。

## 危险线清晰度调整

危险线改用不透明深棕8单位外描边、浅金4单位内线，虚线每段22单位、间隔10单位；左侧增加描边“危险线”文字。越线时内线变为红色并闪烁，倒计时继续使用真实危险计时。位置仍为 `DANGER_Y`，不改变判定规则。类型检查、9项规则检查与 Web Mobile 构建通过，390×694 正常/危险两种状态截图已检查，无浏览器页面错误；未进行真机验证。截图为 `ui-screenshots/danger-normal.png` 和 `ui-screenshots/danger-alert.png`。
