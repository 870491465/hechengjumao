# 猫箱挤挤 · 2D 玩法原型

Cocos Creator **3.8.8**，Box2D 2D。打开 `assets/scenes/CatBox.scene`，点击浏览器预览即可试玩。

已接入正式美术：房间、纸箱分层、标题、晃箱按钮和完整 1–8 级猫；资源缺失时保留数字球兜底。碰撞轮廓默认关闭。

已有 Web Mobile 构建时，在项目根目录执行 `npm run serve`，打开 `http://localhost:8080`。手机同 Wi-Fi 访问电脑局域网 IP 的 8080 端口。
